## 关键教训（可复用）

1. **v0.1 规则逻辑写反了**：Hippo 分层的 `sign 一致` 要求，会把"YAP/TAZ 缺失后响应被彻底抹平"的基因判为 ambiguous（Δ≈0 符号随机抖动）。结果 CTGF/CYR61/ANKRD1/AMOTL2 全部被踢出 HD 集合，HD_up 里剩下 9/13 是 snoRNA/假基因。修正为"仅按幅度塌陷（ratio ≤ 0.5）判定依赖"，新增 `reversed` 类。→ **判定"依赖"应看幅度塌陷，不看符号。**
2. **缺 biotype 过滤会让低方差非编码基因蹭进签名**：n=3 的 Welch 检验下，SNORA1/MTND1P27/RNA5SP284 这类低表达位点轻易显著。已改为 GENCODE v24lift37 `gene_type == protein_coding`（19947/58266）。**注释驱动 > symbol 模式启发式。**
3. **基线表达混杂是这类"签名投射"分析的头号伪影**：GSE111216 背景含 40–58% 零表达位点，签名基因（FPKM>1 筛选而来）与背景的基线分布 KS D≈0.49。未匹配的随机置换零分布会在**包括血液在内的每个组织**都给出 p=1e-4 ~ 0.04 的"显著"。必须用**仅表达基因作背景 + 表达分位分层匹配的零分布**。
4. **两个静默 bug 差点产出假阳性**：
   - `ranks = np.arange(len(df))` 按行序赋秩而非按 log2FC 排序赋秩 → 8 个组织拿到完全相同的 z 值。识别信号就是"不同对比的统计量一模一样"。
   - `build_counts` 把 group 存成小写 `sni`，下游按 `SNI` 匹配 → 分组为空 → 均值 NaN → 置换检验把 NaN 当"极度显著"吐 p=0。已在 `exact_perm_diff` 加断言禁止空臂/非有限值。
5. **n=4 vs 4 的精确置换下界是 1/35=0.0286**：结果恰好停在下界时，必须明说"无法与下界本身区分"，不能当成 p=0.029 的精确证据。

**阳性对照 PASS → 管线灵敏度已证实：能检出真实信号（g=4.43，完全分离）。**
→ HD_up 的 g=0.252 与阳性对照相差 **17.6 倍**，因此 Stage B 的阴性**不是功效不足，而是可信的有界阴性发现**。

**同时发现 Stage A 的结论层级错误**：
- 主终点 DRG-SNI：P=0.597, q=0.682（不显著）
- **阴性对照 BLD-SNI：P=0.0009, q=0.0072（显著！）**
- 协议 §5.3 明文：「若阴性对照与主终点同等显著，则结论不得成立」
- → Stage A **不得表述为"阴性结果"，必须表述为"检验无效"**（统计量捕捉到的是与组织无关的全局伪影）

这一修正比原来的"阴性结论"**更有价值**：它直接质疑了既往疼痛转录组学反复报道的 "ECM organization 富集" 缺乏组织特异性。
